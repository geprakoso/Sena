        Route map

        Routing mengikuti App Router. Homepage memecah konten ke section anchor, sedangkan case study detail digenerate dari data slug statis dan database SQLite.

        / home landing /portfolio listing + filter /portfolio/[slug] static detail + DB /contact conversion page /admin case study management /admin/new create new /admin/[id]/edit edit existing

        Anchor di homepage

        Navigasi internal home memakai anchor section. CTA primer membawa user ke route contact, sedangkan CTA sekunder tetap di landing dan mendorong eksplorasi portofolio.

        #home #services #about #case-studies #contact

        I18n dan state global

        Bahasa aktif dibaca dari cookie `lang`. `Navbar` mengubah cookie lewat browser, lalu `router.refresh()` memaksa server component memuat dictionary baru dari file `.lang`.

        cookies().get("lang") document.cookie = lang=... router.refresh() en.lang / id.lang

        Data source utama

        Konten aplikasi berasal dari dua sumber: `lib/content.ts` untuk data statis (services, approach, nav items) dan SQLite database `data/case-studies.db` untuk case study dinamis yang dikelola via admin panel.

        getServices(dict) getApproachSteps(dict) getPortfolioProjects(dict) getCaseStudyDetailBySlugFromDb(slug) SQLite DB

        Admin CRUD flow

        Admin panel memiliki layout terpisah (`app/admin/layout.tsx`) dengan dashboard untuk manage case studies. CRUD operations menggunakan server actions (`lib/actions.ts`) yang berkomunikasi langsung dengan SQLite via `lib/db.ts`.

        createCaseStudy() updateCaseStudyAction() deleteCaseStudyAction() revalidatePath() file upload

        Component architecture

        Komponen terorganisir dalam 4 kategori: `admin/` (form, delete button), `case-study/` (13 components untuk detail page), `layout/` (Navbar, Footer), dan `sections/` (6 homepage sections). Semua ada di folder `components/` root.

        components/admin/ 3 files components/case-study/ 13 files components/layout/ 2 files components/sections/ 6 files
        Contact page saat ini adalah titik conversion utama. Route ini tidak muncul di `getNavItems()`, jadi akses utama ke `/contact` datang dari CTA di hero, CTA section, case study CTA, dan tombol "Let's Talk" di navbar. Admin panel (`/admin`) memiliki layout terpisah dan mengelola case studies via SQLite database dengan server actions untuk CRUD operations + file upload. Footer juga masih berisi beberapa tautan placeholder seperti sosial `#twitter`, `#linkedin`, `#github`, serta legal links `#`.
