        Flow Audit

        5 catatan
        Warn
        Language switch timing tidak persis seperti dokumentasi lama

        Di Navbar, handleLangChange() memanggil setLang() lalu router.refresh(). Cookie baru ditulis di useEffect setelah state berubah, jadi refresh bisa terjadi sebelum cookie benar-benar tersimpan.

        Warn
        Slug DB baru tidak masuk generateStaticParams()

        /portfolio/[slug] membangun static params dari getCaseStudyDetails() static content, sedangkan admin menulis data baru ke SQLite. Runtime lookup DB tetap ada, tetapi build-time slug list tidak mencakup case study dari admin.

        Warn
        Revalidation public detail belum dicatat di action

        Create/update/delete hanya memanggil revalidatePath('/admin') dan edit path. Kalau halaman public detail/listing menjadi cached atau static, flow invalidasi /portfolio dan /portfolio/[slug] perlu eksplisit.

        Added
        Admin “View” dan admin layout sudah ditambahkan ke graph

        Flow lama belum menonjolkan link dari row admin ke public detail dan link View Site di layout admin. Keduanya sekarang ada di mode Admin/Public Bridge.

        Added
        Root metadata, env logo, scroll state, dan mobile menu ikut dipetakan

        Ini bukan route baru, tetapi penting untuk struktur global karena memengaruhi SEO, branding, dan navigasi client di semua halaman publik.
